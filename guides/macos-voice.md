# macOS 语音输入

本页按 macos-v0.52.0 整理。语音输入在设置应用的「语音输入」页配置，与 v0.50 及更早版本输入法菜单里的「语音输入设置…」窗口不同。iOS 不允许键盘直接录音：iOS 测试版需要先在水杉 App 里录音识别，再回到键盘插入结果，不在本页范围。

安装、日常输入和数据管理见 [macOS 使用指南](macos.md)。

## 配置

打开水杉输入法设置的「语音输入」页，在「识别服务」中选择一种：

- 云端服务：豆包（默认）、SiliconFlow、OpenAI、Groq、EveryAPI 或 Mistral · Voxtral。填写所选服务的 API Key 后才能使用，默认为空。
- 本地模型（离线）：在页面下方下载一个模型（中英流式、快速整句或高精度）并点「使用」。下载只连接 GitHub 或你配置的镜像；之后录音和识别都在本机完成，不需要 API Key。你自己添加的词条会作为热词提高专有名词的识别率。
- macOS 系统识别：使用系统自带的语音识别。macOS 26 起在设备端识别；更早的系统在支持时要求设备端识别，否则是否上传由系统决定。

文本润色可单独开启，默认服务是 DeepSeek，但不填密钥就不会发送任何文本。即使识别使用本地模型或系统识别，启用润色并填写密钥后，转写文本仍会发往润色服务。同一页还可以选择录音设备、关闭开始／结束提示音，以及设置录音时是否静音其他声音（默认开启，会静音整个默认输出设备，录音结束后恢复）。

## 录音与上屏

在要输入文字的应用里切换到水杉，然后：

- 按住右 Option 录音，松开结束并识别；按住期间按空格可锁定录音，之后无需继续按住。
- 按 `Control + F9` 开始录音，再按一次结束。这个快捷键需要在「系统设置 › 隐私与安全性 › 输入监控」中允许水杉输入法，否则按下没有反应；首次授权后请重新按键。
- 也可使用输入法菜单的「开始/结束语音输入」或悬浮工具栏。

「按住右 Control + 右 Option 录音」和「按住 Control + Command 录音」默认关闭，可在「语音快捷键」中开启，不需要的快捷键也可以在那里关闭。录音中按 `Esc` 取消。第一次录音会请求麦克风权限。识别完成后文本输入到当前应用；使用流式识别时，录音过程中就能看到转写预览。

云端批量识别的单次录音上限约 11 分钟，到达上限时自动结束并提交已录的部分；豆包流式识别和本地模型不受这条限制。

## 数据与权限

选择云端服务时会上传本次录音；文本润色会上传转写文本；服务收到的数据无法通过取消操作收回。本地模型全程在本机运行，识别期间不发出网络请求。

如果无法录音，请在 macOS 系统设置的「隐私与安全性 → 麦克风」中检查水杉的权限，并确认所选录音设备可用。识别失败时，浮层会显示服务返回的原因；检查 API Key、服务地址、模型或账户权限。隐私详情见 macos-v0.52.0 的[隐私说明](https://github.com/metasequoiaime/msime/blob/macos-v0.52.0/PRIVACY.md)。
