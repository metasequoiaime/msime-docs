# iOS 使用指南

水杉 iOS 版是一个系统键盘扩展，由键盘和同名的设置 App 组成，支持 iOS 17 及以上的 iPhone 和 iPad。它目前是测试版，通过 TestFlight 公开测试分发，尚未上架 App Store，原因见[常见问题](https://msime.app/faq/)里的「iOS 版为什么不在 App Store？」。本文按 [msime](https://github.com/metasequoiaime/msime) 当前 `develop` 源码核对；安装包功能和版本以对应 Release 为准。不同版本可能存在功能差异，请同时查看对应 Release。

## 安装与更新

先在 iPhone 或 iPad 上安装 Apple 的 TestFlight，再打开[水杉的 TestFlight 公开测试链接](https://testflight.apple.com/join/bUzPvyqt)加入测试并安装。TestFlight 的每个构建有效期为 90 天，到期前在 TestFlight 里更新即可，不需要重新加入。链接提示“不接受新测试员”时，请稍后再试，或到 [Telegram 群](https://t.me/msimegroup)确认当前开放状态。

## 启用键盘

第一次打开 App 会有新手引导，按提示操作即可；跳过了也可以在「我的 → 新手引导」重新查看，或照下面的步骤做：

1. 打开系统的「设置 → 通用 → 键盘 → 键盘」。
2. 点「添加新键盘」，选择水杉输入法。
3. 在任意输入框里长按地球键，选择水杉输入法。

App 的「我的 → 帮助与反馈 → 使用帮助」里有「打开系统键盘设置」，可以直接跳到系统设置里对应的位置。键盘列表里看不到水杉时，先确认已经添加，再长按地球键翻一下列表。

## 输入方案

在 App 的「设置 → 输入」里选择。可选的方案有全拼 26 键、全拼 9 键、小鹤双拼、自然码双拼、微软双拼、首道双拼、五笔、手写、日语 26 键和 9 键、韩语 26 键、粤拼 26 键、大千注音和越南语 26 键，另有一个「高情商回复」键盘。每个方案右边的开关决定它是否出现在键盘的快捷切换里，至少保留一种；点方案名称把它设为当前方案。粤拼、大千注音和越南语默认不启用，需要时打开对应开关。

打开五笔后，同一页会出现「五笔」一组，可以在「码表」里选 86 或 98，两个版本各用各的词库，个人词条和调频记录也分开保存。同一组还有「编码打不出时用拼音候选」和「候选显示剩余编码」两个开关。

「设置 → 输入」下面还有「模糊音」「标点」「辅助码」「快捷模式」等子页。辅助码只用于全拼和双拼：组字时先点 Shift 再输入的字母用来缩小候选。全拼和双拼各有一组设置，可以分别关闭辅助码、选择辅助码方案（蓝天小雨点、自然码、首右2.0、首右plus、小鹤、加加），以及决定是否「在候选栏中显示辅助码」；没改过时双拼用蓝天小雨点并在候选栏显示，全拼用自然码且不显示。

## 皮肤与键盘

- **皮肤**：在「设置 → 主题」里选择，也可以自定义主题。
- **键盘高度与按键间距**：在「设置 → 键盘」里调整；26 键、9 键等键盘布局在键盘上的布局按钮里切换。
- **候选栏与工具栏**：分别在「设置 → 候选栏」和「设置 → 键盘工具栏」里调整。

## 常用操作

- **选择候选**：点候选栏里的词上屏；候选多于一行时，点右端的箭头展开整页。
- **管理候选词**：全拼 26 键、9 键、双拼和五笔可以长按候选词，选择优先显示、固定到前五位中的某一位、取消固定或删除词条；删除需要再次确认。
- **导入词库**：在「设置 → 词库 → 个人词库」里点「从文件导入词条」，来源可以是 JSON 文件、纯中文词表或词库文件，每次最多 128 条、文件不超过 1 MB。词库文件的格式与电脑版相同，见[从其他输入法迁移](https://github.com/metasequoiaime/msime-docs/blob/main/guides/migration.md)。

## 完全访问与联网功能

键盘默认离线，不打开「允许完全访问」也可以正常打字。打字统计、手写第一次下载识别模型和诊断日志需要它，需要时到「设置 → 通用 → 键盘 → 键盘 → 水杉输入法」里打开。哪些功能需要完全访问，见[常见问题](https://msime.app/faq/)里的「iOS 键盘要不要打开「允许完全访问」？」。

云词库、皮肤社区这些功能要联网并登录水杉账号，账号状态在「我的」里查看。登录后「我的」里会出现「设置同步」和「云词库」：「设置同步」可以上传本机设置或下载并应用云端设置，范围是输入方案、简繁体、键盘声音与触感、词库学习开关和皮肤，凭据、联网授权和输入内容不会随设置上传。

## 桌面 CLI 与 MCP

iOS 键盘扩展和设置 App 不包含桌面版的 `msime`、`msime-mcp` 或 MCP stdio 服务。CLI/MCP 仅随 macOS、Linux、Windows 桌面安装包提供；需要测试候选或连接 AI 助手时，请在桌面版上运行对应命令。桌面命令与权限说明见[命令行与 MCP](cli-mcp.md)。

## 反馈问题

在 App 的「我的 → 帮助与反馈」里选择类型、写下发生了什么，再点「复制报告」或「在 GitHub 提交」；报告会附上 App 版本、系统版本和设备型号。也可以先搜索 [msime Issues](https://github.com/metasequoiaime/msime/issues)，没有相同问题时再新建。

键盘出问题时，在同一页打开「诊断日志」里的「记录键盘诊断日志」，复现一次后点「分享日志」附在反馈里。日志只记录事件名称，不记录按键、输入的文字、候选、账号或服务响应，保存在本机；键盘要开启完全访问才能写入，开关在下次弹出键盘时生效。
