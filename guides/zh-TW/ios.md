# iOS 使用指南

水杉 iOS 版是一個系統鍵盤延伸功能，由鍵盤和同名的設定 App 組成，支援 iOS 17 及以上的 iPhone 和 iPad。它目前是測試版，透過 TestFlight 公開測試分發，尚未上架 App Store，原因見[常見問題](https://msime.app/zh-TW/faq/)裡的「iOS 版為什麼不在 App Store？」。本文按 [msime](https://github.com/metasequoiaime/msime) 當前 `develop` 原始碼核對；安裝包功能和版本以對應 Release 為準。不同版本可能存在功能差異，請同時檢視對應 Release。

## 安裝與更新

先在 iPhone 或 iPad 上安裝 Apple 的 TestFlight，再開啟[水杉的 TestFlight 公開測試連結](https://testflight.apple.com/join/bUzPvyqt)加入測試並安裝。TestFlight 的每個建置有效期為 90 天，到期前在 TestFlight 裡更新即可，不需要重新加入。連結提示“不接受新測試員”時，請稍後再試，或到 [Telegram 群組](https://t.me/msimegroup)確認目前開放狀態。

## 啟用鍵盤

第一次開啟 App 會有新手引導，按提示操作即可；跳過了也可以在「我的 → 新手引导」重新檢視，或照下面的步驟做：

1. 開啟系統的「設定 → 一般 → 鍵盤 → 鍵盤」。
2. 點「加入新鍵盤」，選擇水杉输入法。
3. 在任意輸入框裡長按地球鍵，選擇水杉输入法。

App 的「我的 → 帮助与反馈 → 使用帮助」裡有「打开系统键盘设置」，可以直接跳到系統設定裡對應的位置。鍵盤清單裡看不到水杉時，先確認已經加入，再長按地球鍵翻一下清單。

## 輸入方案

在 App 的「设置 → 输入」裡選擇。可選的方案有全拼 26 鍵、全拼 9 鍵、小鶴雙拼、自然碼雙拼、微軟雙拼、首道雙拼、五筆、手寫、日語 26 鍵和 9 鍵、韓語 26 鍵、粵拼 26 鍵、大千注音和越南語 26 鍵，另有一個「高情商回复」鍵盤。每個方案右邊的開關決定它是否出現在鍵盤的快速切換裡，至少保留一種；點方案名稱把它設為目前方案。粵拼、大千注音和越南語預設不啟用，需要時開啟對應開關。

開啟五筆後，同一頁會出現「五笔」一組，可以在「码表」裡選 86 或 98，兩個版本各用各的詞庫，個人詞條和調頻記錄也分開保存。同一組還有「编码打不出时用拼音候选」和「候选显示剩余编码」兩個開關。

「设置 → 输入」下面還有「模糊音」「标点」「辅助码」「快捷模式」等子頁。輔助碼只用於全拼和雙拼：組字時先點 Shift 再輸入的字母用來縮小候選字範圍。全拼和雙拼各有一組設定，可以分別關閉輔助碼、選擇輔助碼方案（藍天小雨點、自然碼、首右2.0、首右plus、小鶴、加加），以及決定是否「在候选栏中显示辅助码」；沒改過時雙拼用藍天小雨點並在候選欄顯示，全拼用自然碼且不顯示。

## 佈景主題與鍵盤

- **佈景主題**：在「设置 → 主题」裡選擇，也可以自訂主題。
- **鍵盤高度與按鍵間距**：在「设置 → 键盘」裡調整；26 鍵、9 鍵等鍵盤配置在鍵盤上的配置按鈕裡切換。
- **候選欄與工具列**：分別在「设置 → 候选栏」和「设置 → 键盘工具栏」裡調整。

## 常用操作

- **選擇候選字**：點候選欄裡的詞送出；候選字多於一行時，點右端的箭頭展開整頁。
- **管理候選詞**：全拼 26 鍵、9 鍵、雙拼和五筆可以長按候選詞，選擇優先顯示、固定到前五位中的某一位、取消固定或刪除詞條；刪除需要再次確認。
- **匯入詞庫**：在「设置 → 词库 → 个人词库」裡點「从文件导入词条」，來源可以是 JSON 檔案、純中文詞表或詞庫檔案，每次最多 128 條、檔案不超過 1 MB。詞庫檔案的格式與電腦版相同，見[從其他輸入法遷移](https://github.com/metasequoiaime/msime-docs/blob/main/guides/zh-TW/migration.md)。

## 完全取用與連網功能

鍵盤預設離線，不開啟「允许完全访问」也可以正常打字。打字統計、手寫第一次下載辨識模型和診斷日誌需要它，需要時到「設定 → 一般 → 鍵盤 → 鍵盤 → 水杉输入法」裡開啟。哪些功能需要完全取用，見[常見問題](https://msime.app/zh-TW/faq/)裡的「iOS 鍵盤要不要開啟「允许完全访问」？」。

雲端詞庫、佈景主題社群這些功能要連網並登入水杉帳號，帳號狀態在「我的」裡檢視。登入後「我的」裡會出現「设置同步」和「云词库」：「设置同步」可以上傳本機設定或下載並套用雲端設定，範圍是輸入方案、簡繁體、鍵盤聲音與觸感、詞庫學習開關和佈景主題，憑證、連網授權和輸入內容不會隨設定上傳。

## 桌面 CLI 與 MCP

iOS 鍵盤擴充功能和設定 App 不包含桌面版的 `msime`、`msime-mcp` 或 MCP stdio 服務。CLI/MCP 僅隨 macOS、Linux、Windows 桌面安裝包提供；需要測試候選或連線 AI 助手時，請在桌面版執行對應命令。桌面命令說明見[命令列與 MCP](../cli-mcp.md)。

## 回報問題

在 App 的「我的 → 帮助与反馈」裡選擇類型、寫下發生了什麼，再點「复制报告」或「在 GitHub 提交」；報告會附上 App 版本、系統版本和裝置型號。也可以先搜尋 [msime Issues](https://github.com/metasequoiaime/msime/issues)，沒有相同問題時再新建。

鍵盤出問題時，在同一頁開啟「诊断日志」裡的「记录键盘诊断日志」，重現一次後點「分享日志」附在回報裡。日誌只記錄事件名稱，不記錄按鍵、輸入的文字、候選字、帳號或服務回應，保存在本機；鍵盤要開啟完全取用才能寫入，開關在下次彈出鍵盤時生效。

同一頁還有 QQ 交流群 829919142 和 [Telegram 群組](https://t.me/msimegroup)的入口。
