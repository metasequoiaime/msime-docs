# Android 使用指南

水杉 Android 版是一個系統輸入法，由鍵盤和同名的設定應用程式組成，支援 Android 9 以上版本，目前是測試版，尚未上架應用程式商店。本文按 [msime](https://github.com/metasequoiaime/msime) 當前 `develop` 原始碼核對；安裝包功能和版本以對應 Release 為準。不同版本可能存在功能差異，請同時查看對應 Release。

## 下載與版本

從[蒲公英下載頁](https://www.pgyer.com/msime)或 [msime Releases](https://github.com/metasequoiaime/msime/releases) 中標籤以 `android-v` 開頭的版本下載 APK。每個 Release 提供幾個互相獨立的版本：

- `msime-android.apk`：完整版，包含全拼、雙拼、五筆、手寫等全部方案。
- `msime-android-pinyin.apk`、`msime-android-wubi.apk`：只帶拼音或五筆的「水杉拼音」「水杉五笔」。五筆版只有五筆和手寫，預設開啟五筆拼音混輸。
- `msime-android-japanese.apk`、`msime-android-vietnamese.apk`、`msime-android-tibetan.apk`：水杉日語、水杉越南語、水杉藏文，沒有中文手寫。

這些版本是不同的應用程式，可以同時裝在一支手機上，彼此的設定和詞庫互不影響。每個 APK 旁邊的 `.sha256` 檔案可用來核對下載是否完整。

安裝商店外的 APK 時，系統可能提示「未經檢測」或「存在風險」，需要允許瀏覽器或檔案管理員「安裝不明應用程式」。

## 啟用鍵盤

第一次開啟應用程式會有新手引導，按提示操作即可；跳過了也可以在「我的 → 使用帮助」裡找到同樣的步驟：

1. 開啟系統的「設定 → 系統 → 語言與輸入設定 → 螢幕小鍵盤」（各品牌手機的選單名稱略有不同），或者點應用程式裡的「打开系统键盘设置」直接跳過去。
2. 在螢幕小鍵盤清單裡開啟水杉輸入法的開關，按提示確認。
3. 點任意輸入框，再點右下角的鍵盤圖示，選擇水杉輸入法。

應用程式的「设置」頁會顯示鍵盤是否「已在系统中启用」和是否已「设为默认输入法」，沒完成時可以直接點「去启用」「设为默认」。鍵盤清單裡看不到水杉時，先確認開關已開啟，再點輸入框右下角的鍵盤圖示翻一下清單。

## 升級

新版本直接覆蓋安裝，詞庫和設定不會遺失；所有版本用同一把金鑰簽署。也可以在應用程式的「我的 → 关于」裡點「检查更新」，或開啟「自动更新」：每天連網時檢查一次，下載好後通知你安裝。「更新通道」可以選穩定版或更早拿到新功能的預覽版。第一次從應用程式內安裝更新時，系統會要求允許水杉「安裝不明應用程式」。

0.3.0 在部分裝置上會提示「词库准备失败」、只能直接輸入，Android 9 上開啟應用程式會閃退，這兩個問題都已在 0.3.1 修復，遇到時請升級到 0.3.1 或更新版本。

## 中英文切換

點鍵盤上的「中/英」鍵切換中文和英文。預設進入中文，切換後會按應用程式記住：在某個應用程式裡換成英文，下次回到這個應用程式還是英文。網址、電子郵件和密碼輸入框會暫時進入英文，離開後恢復原來的狀態；密碼框裡點「中/英」不起作用。

0.3.1 裡還有一個問題：很多聊天框、搜尋框和網頁輸入框（宣告了「不需要輸入建議」的輸入框）每次都從英文開始。這個問題已經修復（[#5998](https://github.com/metasequoiaime/msime/issues/5998)），修復從 0.3.1 之後的下一個 Android 版本起生效。

長按「中/英」鍵會彈出系統的輸入法選擇框，可以暫時換到密碼管理工具之類的其他鍵盤。

## 9 鍵與 26 鍵

在「设置 → 键盘 → 布局 → 中文键盘」裡選擇 26 鍵或 9 鍵。目前方案只有一種鍵盤時，這一項會提示到「输入」裡換方案；只帶一種方案的版本（例如五筆版）也只有一種鍵盤。

要換輸入方案（全拼、雙拼、五筆等），點鍵盤上「拼26」這類方案角標，在輸入方案裡選擇；方案和語言的完整清單在「设置 → 输入 → 语言与方案」。

同一頁的「布局」裡還可以調整鍵盤高度、按鍵間距和行距，以及 9 鍵左側符號欄的內容。

## 輸入方案、雙拼與輔助碼

輸入方案在「设置 → 输入 → 语言与方案」裡切換。點「普通话」可以選全拼、雙拼（小鶴、自然碼、微軟、首道）、五筆（86 或 98）、注音、注音 9 鍵、筆畫和手寫；全拼用 26 鍵還是 9 鍵，在「设置 → 键盘 → 布局 → 中文键盘」裡選。注音和筆畫第一次選用時要先下載詞庫。粵語（粵拼）、日語、韓語、越南語和藏語在同一頁的「添加语言」裡新增，第一次新增時同樣要下載對應的詞典。以上是完整版的方案，水杉拼音、水杉五筆等獨立版本只帶各自的方案。

輔助碼在「设置 → 输入 → 辅助码」裡設定：全拼或雙拼組字時，先按 Shift 再輸入的字母用來縮小候選字範圍。「辅助码方案」按目前是全拼還是雙拼分別保存，可選自然碼、小鶴、藍天小雨點、首右2.0、首右plus、加加等；沒改過時雙拼用藍天小雨點，全拼用自然碼。

0.3.1 裡輔助碼關不掉，這一頁只有「辅助码方案」。從 0.3.1 之後的下一個 Android 版本起，同一處新增「启用辅助码」開關，關掉後 Shift 後面的字母不再用來縮小候選字範圍；還新增「在候选栏中显示双拼辅助码」（全拼方案下是「在候选栏中显示全拼辅助码」），關掉後候選字旁不再標註輔助碼，Shift 篩選照常可用。

雙拼方案的 26 鍵鍵盤會在字母鍵底部標出這個鍵代表的聲母和韻母。0.3.1 裡這個標註關不掉；從 0.3.1 之後的下一個 Android 版本起，可以在「设置 → 键盘 → 布局 → 双拼键位提示」裡關閉，關閉後鍵面只留字母。

## 整句聯想

輸入多個拼音音節時，鍵盤會用詞庫組出整句候選。「设置 → 表达 → 整句联想」有三檔：「关闭」、「标准」（預設，只用詞庫組句）和「增强」。「增强」在標準之上加入開源的 chinese-ime-lm 整句重排模型，結合前文在整句候選中重新挑選首選，計算會多一些。水杉五筆等只帶單一方案的獨立版本不帶這個模型，沒有「增强」這一檔。它的作用、實測效果與代價見官網的[神經聯想](https://msime.app/zh-TW/model/)頁面。

## 浮動鍵盤、單手模式與平板

浮動鍵盤讓整個鍵盤縮成一塊面板懸在應用程式上面，應用程式不再被頂起，鍵盤擋住輸入框時把面板拖開即可。按住面板頂部的橫條拖動位置，點橫條右端的「停靠」回到底部的完整鍵盤。開啟方式有三種：「设置 → 键盘 → 布局」裡的「浮动键盘」開關、鍵盤功能面板裡的「浮动键盘」，以及工具列按鈕（預設不顯示，在「设置 → 键盘 → 键盘工具栏」裡開啟）。

單手模式在鍵盤功能面板裡開啟，鍵盤收窄並推向一側，另一側可以換邊或退出。浮動鍵盤開啟時單手模式不生效，停靠後自動恢復。

平板、展開的摺疊手機和二合一裝置會使用置中的大螢幕鍵盤。「设置 → 键盘 → 布局」裡的「横屏分离式键盘」只在平板橫向時生效，把 26 鍵和韓文鍵盤分成左右兩半，方便雙手握持時用拇指打字。

## 外接鍵盤

用實體鍵盤打字時，螢幕鍵盤會自動收起，只留下頂部一行：閒置時是工具列，打字時是候選條。點工具列最右邊朝上的箭頭可以回到完整的螢幕鍵盤，下一次用實體鍵盤打字時會再收起；拔掉或闔上鍵盤後自動退出這個模式。

實體鍵盤上可以用 Shift+Space、Ctrl+Alt+Space 或單按 Shift、Ctrl 切換中英文，Ctrl+Shift+F 切換簡繁，Alt+Shift+H 切換全形。候選字前面標了數字時，按數字鍵 1–9 選擇對應的候選字。

## 語音輸入與手寫

語音輸入的設定在「设置 → 语音输入」：辨識語言可選普通話、粵語、英語或普通話 + 英語；「启动方式」可選長按空白鍵、工具列按鈕或關閉。第一次使用時需要允許水杉使用麥克風。開啟「离线识别」並下載「本地语音运行库」後，沒有網路時會用本機模型辨識，準確率略低。「上传语音以改进识别」預設關閉，開啟後音訊和辨識結果會上傳到水杉雲並保存 180 天，隱私模式、密碼框和不允許個人化學習的輸入框裡不會上傳。

手寫輸入的設定在「设置 → 手写输入」。手寫第一次使用時需要連網下載辨識模型，之後在裝置上辨識。

### 不連網安裝本機語音

本機辨識需要兩樣東西：「本地语音运行库」和至少一個本機模型。完整版和水杉拼音的安裝包不帶執行庫，要另外準備；其他版本的安裝包自帶執行庫，只需準備模型。兩樣都可以在應用程式裡直接下載；網路慢或一直下載失敗時，可以先用手機瀏覽器或電腦把檔案下載好（電腦上下載的要先傳到手機裡），再在應用程式裡從檔案匯入。0.4.1 起的版本支援從檔案匯入，以下按 0.6.0 的介面說明。

1. 在「设置 → 语音输入」的「识别」分頁開啟「离线识别」，或者在「服务」分頁把辨識服務選成「本地模型」。之後「服务」分頁裡會出現「本地识别准备」和「本地模型」兩組。開啟離線辨識或選用本機模型時，應用程式會自動開始下載執行庫。
2. 匯入執行庫：在「本地识别准备」裡點「从文件导入运行库」。執行庫正在下載時這一項不會顯示，先在「本地语音运行库」那一行點「取消」；執行庫顯示「已就绪」時也不會顯示，不需要再匯入。
3. 匯入模型：在「本地模型」裡點「从文件导入」，再選一個還沒裝好的模型。正在下載的模型不在這個清單裡，要先在它那一行點「取消」。
4. 對話框會列出這一項要下載的檔案和大小，點「下载地址」可以直接用瀏覽器開啟。檔案都下載好後點「选择文件」，把它們一起選上。應用程式按長度和內容（SHA-256）辨認檔案，改了檔名也沒關係；檔案不完整或不對時什麼都不會安裝。

## 常用操作

- **選擇候選字**：點候選欄裡的詞送出；候選字多於一行時，點右端的箭頭展開整頁。
- **刪除**：按住刪除鍵會逐漸加速連刪；按住後往上滑，鍵上方會出現「快速删除」框，滑進框裡放開會刪掉游標前的全部文字，滑回框外再放開則什麼也不刪。
- **換佈景主題**：點鍵盤工具列上的衣架圖示，或在「设置 → 皮肤」裡選擇。
- **隱私**：鍵盤預設離線，只有使用雲端候選字、AI、語音、帳號同步等功能時才連網，詳見 [PRIVACY.md](https://github.com/metasequoiaime/msime/blob/develop/PRIVACY.md)。

## 桌面 CLI 與 MCP

Android 發行 APK 是原生輸入法宿主，不包含桌面版的 `msime`、`msime-mcp` 或 MCP stdio 服務。需要查詢候選、驅動測試會話或連線 AI 助手時，請在安裝 macOS、Linux 或 Windows 桌面版的電腦上使用對應 CLI；Android 的設定和輸入資料不會自動提供給桌面 CLI。桌面命令說明見[命令列與 MCP](../cli-mcp.md)。

## 回報問題

在應用程式的「我的 → 帮助与反馈」裡提交，可以附上截圖和診斷資訊；也可以先搜尋 [msime Issues](https://github.com/metasequoiaime/msime/issues)，沒有相同問題時再新建，並寫明手機型號、Android 版本和水杉版本。
