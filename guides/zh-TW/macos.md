# macOS 使用指南

水杉 macOS 版由兩部分組成：系統輸入源「水杉输入法」，以及負責安裝、設定和詞庫管理的設定應用程式 MSIME。目前發布的 DMG 是 universal 套件，Apple 晶片與 Intel Mac 通用，需要 macOS 13 及以上版本。本文按 2026-10-05 發布的 macos-v0.52.0 整理；其他版本的功能以對應 Release 為準。macOS 版由 [msime](https://github.com/metasequoiaime/msime) 儲存庫發布。iOS 版透過 TestFlight 公開連結測試分發，不能用 macOS 安裝套件安裝到 iPhone 或 iPad。

本頁採用臺灣繁體中文用語；引號內的應用程式選項、程式碼、檔名與範例保留原文，方便對照實際介面。

## 下載與安裝

從 [msime Releases](https://github.com/metasequoiaime/msime/releases) 開啟標籤為 `macos-v0.52.0` 的版本；該頁面同時列出 Windows、Linux 等其他平台的發布，請認明 `macos-v` 開頭的標籤。完整版下載 `msime-macos-0.52.0-universal.dmg`。同一版本還提供只含部分方案的水杉五筆、水杉拼音、水杉日語、水杉越南語和水杉藏文（檔名分別含 `wubi`、`pinyin`、`japanese`、`vietnamese`、`tibetan`），幾個版本可以同時安裝，輸入源、設定和資料彼此獨立。

1. 把 DMG 與 `SHA256SUMS` 下載到同一目錄，在該目錄執行 `shasum -a 256 -c --ignore-missing SHA256SUMS`，確認下載的檔案顯示 `OK`。
2. 開啟 DMG，把水杉輸入法（`MSIME.app`）拖進「应用程序」檔案夾。只拖進去而不開啟，系統裡不會出現輸入法。
3. 在「应用程序」裡開啟它。首次開啟會顯示安裝視窗，點「立即安装」把輸入法複製到目前使用者的 `~/Library/Input Methods` 並登記，完成後點「进入设置」。
4. 按設定頁頂部的提示，在「系统设置 → 键盘 → 文字输入 → 输入法 → 编辑…」中新增水杉輸入法；提示裡的「打开键盘设置」按鈕可以直接跳到這裡。
5. 在選單列的輸入法選單中選中水杉，或按 `Control + Space` 切換，開啟文字框輸入 `nihao`，按空格選詞。

這台 Mac 從未裝過水杉時，登記要到下次登入才生效：設定頁會提示登出並重新登入，重新登入後再按第 4 步新增。`/Library/Input Methods` 裡如果還有水杉的舊副本，設定應用程式會請你先用管理員權限把它移到垃圾桶。預設的完整版只內建拼音和五筆所需的核心詞庫；日語、粵拼、注音詞庫和手寫模型在設定裡第一次用到時下載。

也可以用 Homebrew 安裝，cask 下載的是同一個 DMG：

```sh
brew install --cask metasequoiaime/tap/msime
```

其他版本的 cask 是 `msime-wubi`、`msime-pinyin`、`msime-japanese`、`msime-vietnamese` 和 `msime-tibetan`。裝完仍要按上面第 3 步開啟一次應用程式並點「立即安装」。完整版的 cask 還會把 `msime-mcp` 放進 `PATH`，供在終端機裡配置的 AI 助理使用。

## 常用操作

| 操作 | 按鍵或入口 |
| --- | --- |
| 選擇候選 | 空格選首選；`1`～`9` 選擇對應候選，也可點選候選 |
| 提交原始字母 | `Enter` |
| 修改或取消 | `Backspace` 退格；`Esc` 取消 |
| 中英文切換 | 單按 `Shift`、`Shift + Space` 或 `Control + Option + Space`，或輸入法選單；可在設定「快捷键」頁改為單擊 Control 或關閉 |
| 英文候選模式 | `Control + Shift + E` 或輸入法選單 |
| 半形／全形 | 中文模式下 `Option + Shift + H`，任意模式下 `Control + Shift + Space`，或懸浮工具列 |
| 中文／英文標點 | `Control + .`、輸入法選單或懸浮工具列 |
| 簡體／繁體輸出 | `Control + Shift + F`、輸入法選單「繁体输出」或懸浮工具列 |
| 翻頁 | 預設 `-` / `=`、`,` / `.`、`Shift + Tab` / `Tab` 與 Page Up / Page Down；可在設定「输入 → 选词与翻页」中增減，`[` / `]` 和滑鼠滾輪預設關閉 |

組詞中單按 `Shift` 會把已輸入的字母原樣送出後再切到英文；從選單、懸浮工具列或 `Control + Shift + E` 切換時則取消目前組詞，不送出任何內容。全形和中文標點的快捷鍵只改變目前應用程式，不改儲存的設定；設定裡的勾選項是每個應用程式的起始值。簡繁轉換只改變候選展示和送出的文字，不改寫詞庫。

## 設定與候選字視窗

透過輸入法選單的「水杉输入法设置…」、懸浮工具列的設定按鈕，或直接開啟「应用程序」裡的水杉輸入法進入設定。常用頁面包括：

- **「输入」**：中英文預設狀態、選詞與翻頁、雲端候選和中英混輸、候選學習、繁體輸出、快捷模式、模糊音。輸入方案除全拼外還有雙拼（小鶴、自然碼、首道、微軟）、五筆 86／98、日語、韓語、粵拼、注音、越南語和藏文等，也可在輸入法選單的「输入方案」子選單中切換。
- **輔助碼**：全拼和雙拼分別設定開關與方案，可選自然碼、藍天小雨點、首右 2.0、首右 Plus、小鶴等；候選旁顯示輔助碼提示。雙拼還可開啟鍵位提示（預設關閉）。
- **「候选窗口」**：橫排／直排、每頁候選數和字號（12～32）等。
- **「主题」**：跟隨系統、水杉、淺色、紙白、夜青、墨與自訂；外部外觀套件放在 `~/Library/Application Support/app.msime.macos/skins/<id>/` 下。
- **「快捷键」**、**「悬浮工具栏」**、**「语音输入」**、**「手写输入」**、**「词库」**、**「AI 辅助」**、**「账号与同步」**等其他頁面。

正在進行的組詞沿用開始時的設定，新設定在送出文字或取消後用於後續輸入。macOS 27 不允許輸入法替使用者啟用新的輸入源項目：切換到粵拼、注音、越南語、藏文等方案時，如果選單列沒有對應項目，設定頁「输入」裡會列出還需新增的項目和所在語言，按提示在系統設定中手動新增。

## 本地快捷模式

在設定「输入」頁的「快捷模式」中，各模式可單獨開關。下表幾項預設開啟，在中文模式下使用：

| 快捷鍵 | 用途 | 示例 |
| --- | --- | --- |
| `Shift + U` | Unicode 碼點 | `4e00` 對應“一” |
| `Shift + T` | 日期、時間、星期 | `rq`、`sj`、`xq` |
| `Shift + K` | 快捷片語 | 輸入已設定的片語編碼 |
| `Shift + E` / `Shift + M` | Emoji／顏文字 | 輸入全拼、簡拼、雙拼或英文關鍵詞 |
| `Shift + J` | 超級簡拼 | `nh` 檢索“你好”等候選 |
| `Shift + Y` | 臨時英文 | 之後按英文處理，送出後回到中文 |
| `Shift + R` | 臨時日語 | 之後按日語羅馬字處理，送出後回到中文 |

計算與數字（`Shift + V`）、`/` 指令和 `@` 名單預設關閉，可在同一組開啟。關閉某個模式後，對應組合照常輸入大寫字母。臨時日語要先在「输入」頁的「临时日语词库」中下載詞庫。表情也可透過輸入法選單的「水杉表情面板…」或懸浮工具列選單的「表情与符号…」輸入。

## 語音與資料

辨識服務、本地模型、錄音快捷鍵和麥克風權限見 [macOS 語音輸入](macos-voice.md)。選擇雲端辨識時上傳錄音；本地模型和系統辨識不上傳音訊；開啟文字整理並填寫金鑰後，轉寫文字會發往整理服務。

按鍵、組詞和候選學習在本機處理，以下幾項例外：

- **雲端候選**：第一次啟用輸入法時彈出「联网功能」對話框，選「启用云候选」後，會把正在輸入的拼寫發給 Google input-tools 換回一條候選；回答之前不發請求，之後可在「输入」頁的「云候选」更改。
- **候選詞翻譯**：新安裝預設使用「水杉账号」，把目前頁的中文候選詞發到 `api.msime.app`。沒有登入時，輸入法第一次啟用會註冊一個本機匿名帳號。可在「标点与翻译 → 候选词翻译」改選騰訊雲、小牛翻譯、自訂 DeepLX，或不使用線上翻譯。
- **匿名使用統計**：預設開啟，只含版本、平台和隨機安裝識別碼等，不含輸入內容；可在「关于」頁關閉。
- AI 輔助、語音辨識與文字整理預設沒有金鑰，不填寫就不會發出請求。

學習資料、使用者詞庫、下載的資源套件和共用設定位於 `~/Library/Application Support/app.msime.macos/`，可在「维护与诊断 → 数据目录」移到別處。關閉候選學習只影響後續組詞；「词库」頁末的「清除全部学习数据」會永久刪除候選詞頻、使用者詞庫和拼音學習記錄（包括自己新增的詞條），輸入方案等設定不變，請先確認不再需要。備份資料目錄前先切換到其他輸入法，避免複製正在寫入的資料庫。

## 更新與解除安裝

macOS 版沒有應用程式內自動更新。設定「关于」頁的「检查更新」（或懸浮工具列選單的「检查更新…」）查詢新的 `macos-v` 發布，有新版本時點「前往下载」開啟發布頁。下載新 DMG，把應用程式拖進「应用程序」取代舊版並開啟一次，設定應用程式啟動時會重新整理已安裝的輸入法。用 Homebrew 安裝的執行 `brew upgrade --cask msime`。

解除安裝在設定「维护与诊断」頁的「卸载」中點「卸载…」再確認：輸入法移到垃圾桶，預設保留詞庫、學習記錄和偏好；勾選「同时删除词库、偏好与语音密钥」時一併刪除。如果系統設定的輸入源列表裡還有水杉，設定應用程式會先開啟鍵盤設定，請在「文字输入 › 输入源」裡逐個移除後再確認解除安裝。之後把「应用程序」裡的水杉輸入法移到垃圾桶。用 Homebrew 安裝的可執行 `brew uninstall --cask msime`，加 `--zap` 同時刪除設定、詞庫與快取。

## 常見問題與回報

- **輸入源未出現**：確認已開啟設定應用程式並完成「立即安装」；全新安裝後登出並重新登入，再在「系统设置 → 键盘 → 文字输入 → 输入法」中新增；檢查 `/Library/Input Methods` 裡是否有舊副本。
- **快捷鍵輸入大寫字母**：確認目前是中文模式，且該模式在「输入 → 快捷模式」中開著。
- **設定沒有立即生效**：先送出文字或取消目前組詞，再重新輸入。
- **日語、粵拼或手寫無法使用**：在設定中選中對應方案或開啟手寫面板以下載資源套件，並確認能存取 GitHub。
- **語音無結果**：檢查麥克風權限、錄音裝置、模型或服務配置，詳見語音輸入頁。

問題提交到 [msime Issues](https://github.com/metasequoiaime/msime/issues)，附 macOS 與輸入法版本、所用版本（完整版或五筆等）、晶片架構、宿主應用程式和最小重現步驟。共享材料前移除實際輸入內容和憑證。更完整的資料說明見 macos-v0.52.0 的[隱私說明](https://github.com/metasequoiaime/msime/blob/macos-v0.52.0/PRIVACY.md)。
