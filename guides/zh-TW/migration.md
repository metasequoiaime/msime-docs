# 從其他輸入法遷移

從搜狗、微軟拼音或 Rime 換到水杉，最麻煩的一步是把累積多年的自造詞帶過來。本文說明各家能匯出什麼、水杉需要什麼格式，以及怎麼轉換。

本文的匯入格式、預設值和「按來源選擇匯入方式」裡的入口名稱，按 2026-10-01 核對的 Windows 正式版 v0.9.3 原始碼整理，匯入規則在 [msime-windows](https://github.com/metasequoiaime/msime-windows) 的 `server/src/settings/dictionary_validation.cpp` 與 `dictionary_manager.cpp` 裡，可以對照核對。macOS、Linux、Android 和 iOS 的匯入入口與可選格式見[各平台的匯入入口](#各平台的匯入入口)，按 2026-10-12 核對的 macos-v0.52.0、linux-v0.11.0、android-v0.3.1 與 ios-v0.51.5 原始碼整理。

## 水杉需要什麼格式

批次匯入讀取純文字（`.txt`；Rime 詞庫也可以直接選 `.yaml`）。建議使用 **UTF-8**，可帶 BOM；帶 BOM 的 UTF-16 和 GBK/GB18030 編碼也能辨識。換行 LF 或 CRLF 均可，**不要加表頭**，空行和以 `#` 開頭的註解行會被略過。欄與欄之間**只能用真正的 Tab**（`\t`），不能用空白、逗號或分號。

全拼詞庫每行兩欄或三欄，順序固定為詞語、全拼、權重：

```text
你好	ni'hao	10
西安	xi'an	10
水杉输入法	shui'shan'shu'ru'fa	1
```

三條硬性要求：

- 全拼必須是**完整音節**，不能用簡拼；
- 音節數必須等於詞語的字數；
- 權重是非負整數；可以省略，省略時為 `10000`。

建議用 `'` 手動分音節。沒有 `'` 時（空白不算分隔，會先被去掉）輸入法會自動切分，並優先選擇音節數等於字數的切法，所以 `西安` 寫成 `xian` 也會按 `xi'an` 匯入；但音節數相同的不同切法（例如 `fang'an` 與 `fan'gan`）無法靠字數分辨，這類詞仍要寫上 `'`。

五筆與英文詞庫的格式，以及 Windows 版匯入入口的位置，見[Windows 指南的詞庫一節](windows.md#詞庫)；其他平台見下一節。

## 各平台的匯入入口

上面的欄位格式各平台通用：每行 `词语<Tab>编码<Tab>权重`，權重可以省略。拼音詞庫的編碼必須是完整的全拼音節，音節數等於字數，所以**雙拼使用者的拼音欄也要寫全拼**；手上只有雙拼編碼或者沒有讀音時，只保留詞語一欄，用下面各平台的「汉字自动注音」或「纯汉字词表」匯入，由輸入法自動標音。

- **Windows 正式版**：入口和格式見下文「按來源選擇匯入方式」和 [Windows 指南的詞庫一節](windows.md#詞庫)。
- **macOS 與 Linux**：開啟設定的「词库」頁；Linux 也可以從 IBus、Fcitx5 選單裡的「词库…」或執行 `msime-linux-settings --panel dictionary` 直接開啟。先在「本地词库管理」裡選詞庫類型（全拼、86 五筆、98 五筆、英文、快捷短語），再在「导入与导出」裡選檔案格式：「词在前（标准 TSV）」就是上面的格式，「编码在前（Windows TSV）」把編碼放在第一欄，「Rime userdb / dict.yaml」讀取 Rime 詞庫（選 `.yaml` 檔案時自動切到這一項），「汉字自动注音（仅导入）」只在全拼詞庫下出現，每行一個詞，權重統一為 `10000`。點「导入」選擇檔案即可，檔案不超過 32 MB，較大的檔案會自動分批匯入；UTF-8、帶 BOM 的 UTF-16 和 GBK/GB18030 編碼都能辨識。「导出当前类型」匯出所選類型的使用者詞庫。
- **Android**：「设置 → 词库 → 导入词库」，匯入來源可選「文本文件（.txt）」「Rime 词典（.dict.yaml）」和「纯汉字词表（每行一个词）」；文字檔的詞在前、編碼在前兩種欄位順序都能自動辨識。匯入的都是拼音詞條，會成為一個新的詞庫，點進詞庫可以啟用、停用和編輯詞條。單一檔案不超過 16 MB，一個詞庫最多 2 萬條。0.3.1 不能匯入搜狗細胞詞庫（`.scel`）。
- **iOS**：「设置 → 词库 → 个人词库 → 从文件导入词条」，來源可選「JSON 文件」「纯中文词表」和「词库文件」；選「词库文件」時再選詞庫類型和檔案格式（詞在前、編碼在前或 Rime userdb / dict.yaml）。每次最多匯入 128 條，檔案不超過 1 MB，需要 UTF-8 編碼，確認匯入前會先顯示預覽。

## 按來源選擇匯入方式

舊版本文讓你複製引擎儲存庫執行 `convert_user_dictionary.py`。那個儲存庫（msime-engine）已歸檔，指令碼不再維護；它處理的三種純文字來源，Windows 版現在都能在設定裡匯入，不再需要轉換指令碼（逗號分隔文字只需先把逗號換成 Tab）：

| 來源形狀 | 怎麼匯入 | 典型來源 |
| --- | --- | --- |
| `*.dict.yaml`，`...` 分隔符號之後的 `词语<TAB>编码[<TAB>权重]` | 「词库 → 全拼词库」的「批量导入」直接選擇該檔案 | Rime 自訂詞庫 |
| 每行 `词语,拼音` | 把每行第一個逗號換成 Tab 後「批量导入」；或只保留詞語一欄，按下一行處理 | 搜狗匯出的逗號分隔文字 |
| 每行一個詞，無讀音 | 「批量导入纯汉字词组(e.g.人名)到拼音词库」，自動標音，權重統一為 `10000` | 任何只有詞表的來源 |

匯入結束後會提示成功、略過（已存在）和失敗的條數，失敗的前 5 行附行號和原因，例如：

```
成功导入 1274 条，跳过 2 条（已存在），失败 1 条。第 5 行：全拼必须由拼音表中的完整音节组成，不能使用简拼
```

單條錯誤行不會讓整次匯入失敗。純漢字詞組匯入只接受全是漢字的行，含字母、數字、標點或擴充區罕用字的行會失敗。

### 仍然不能直接匯入的格式

**搜狗細胞詞庫（`.scel`）。** 那是私有二進位格式，憑猜測重新實作出來的解析器沒辦法驗證對錯。請先在搜狗用戶端裡把詞庫匯出成文字，再按上表匯入。

## 各家能匯出什麼

### 搜狗拼音

搜狗的**細胞詞庫**（`.scel`）是從官方詞庫下載的專業領域詞庫，不是你自己的詞。這類詞水杉的內建詞庫基本已經涵蓋，通常不需要遷移；真正值得帶走的是你自己造的詞。

在搜狗用戶端的詞庫管理裡把**使用者詞庫**匯出成文字。匯出格式隨版本變化，常見的是每行 `词语,拼音` 或只有詞語一欄——分別按上表的逗號文字和純詞表處理。匯出前先開啟檔案看一眼實際是哪種，不要憑記憶假設。

如果匯出的拼音是 `nihao` 這種未分音節的連寫，換成 Tab 後也可以直接匯入：輸入法會按字數選擇切法。只有音節數相同、切法不同的詞（如 `fangan`）可能切錯；在意的話只保留詞語一欄，用純漢字詞組匯入重新標音。

### 微軟拼音

微軟拼音的自學習詞庫不提供直接的文字匯出入口，能匯出的是**自訂短語**。它的語意與水杉的「快捷短语」對應，不是全拼詞庫——匯入入口在「实用功能 → 快捷短语」，格式見 Windows 指南對應小節，不要塞進全拼詞庫的批次匯入。

自學習累積的詞頻沒有匯出途徑。可行的做法是把常用詞整理成一份詞表，用「批量导入纯汉字词组」匯入，權重統一為 `10000`；需要其他權重時，寫成 `词语<TAB>全拼<TAB>权重` 三欄，用「批量导入」。

### Rime

Rime 的自訂詞庫 `*.dict.yaml` 是純文字，可以直接在「批量导入」裡選擇：`---` 到 `...` 之間的 YAML 標頭和 `#` 註解行會被略過，第三欄必須是非負整數，省略時按預設權重 `10000` 處理；`99.93%`、`0.5` 這類百分比或小數權重會導致該行匯入失敗，先刪掉第三欄或改成整數。Rime 編碼欄用空白分音節，匯入時空白會被去掉後重新切分；想保住 `fan gan` 這類切法，先把編碼欄中的空白替換成 `'`。

注意 Rime 的編碼欄不一定是全拼——如果你用的是雙拼、五筆或注音方案，那一欄是對應方案的編碼，匯入全拼詞庫時會被拒絕，或者更糟，被當成拼音接受但對不上。這種情況下只保留詞語一欄，用純漢字詞組匯入重新標音。86 五筆方案的詞庫可以在「五笔词库」頁用「批量导入」匯入。

Rime 的**使用者詞典**（`*.userdb`）是資料庫目錄，不是文字。用 Rime 內建的 `rime_dict_manager` 匯出成文字之後再「批量导入」。`rime_dict_manager` 匯出的文字就是 `词语<Tab>编码<Tab>次数`，可以直接匯入。同步目錄裡的 `*.userdb.txt` 快照則是 `编码<Tab>词语<Tab>c=…`，編碼在前，要先對調前兩欄；對調後第三欄的 `c=…` 按預設權重 `10000` 處理。

## 匯入之後

- 匯入不會覆寫已有條目：**已存在的詞條會略過**，原有權重保留。所以先匯入再調頻，順序反了會白調。
- 部分失敗時會回傳行號。按行號檢查 Tab、欄數、權重和音節數，修好失敗行重新匯入即可，已成功的條目不會重複。
- 匯入的是你的使用者詞庫，解除安裝時會隨 `msime_user.db` 一起刪除。遷移完成後建議先匯出一份備份。

## 反過來：從水杉匯出

「词库」頁的「导出词库」可以分別匯出拼音、五筆和英文使用者詞庫，格式與匯入格式相同；拼音使用者詞庫只匯出多字詞。這份檔案既是備份，也是換到別的輸入法時的遷移來源。快捷短語的匯出入口在「实用功能 → 快捷短语」。
