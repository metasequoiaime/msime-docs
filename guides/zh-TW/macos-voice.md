# macOS 語音輸入

本頁按 macos-v0.52.0 整理。語音輸入在設定應用程式的「语音输入」頁配置，與 v0.50 及更早版本輸入法選單裡的「语音输入设置…」視窗不同。iOS 不允許鍵盤直接錄音：iOS 測試版需要先在水杉 App 裡錄音辨識，再回到鍵盤插入結果，不在本頁範圍。

本頁採用臺灣繁體中文用語；引號內的應用程式選項、程式碼、檔名與範例保留原文，方便對照實際介面。

安裝、日常輸入和資料管理見 [macOS 使用指南](macos.md)。

## 配置

開啟水杉輸入法設定的「语音输入」頁，在「识别服务」中選擇一種：

- 雲端服務：豆包（預設）、SiliconFlow、OpenAI、Groq、EveryAPI 或 Mistral · Voxtral。填寫所選服務的 API Key 後才能使用，預設為空。
- 本地模型（離線）：在頁面下方下載一個模型（「中英流式」、「快速整句」或「高精度」）並點「使用」。下載只連線 GitHub 或你配置的鏡像；之後錄音和辨識都在本機完成，不需要 API Key。你自己新增的詞條會作為熱詞提高專有名詞的辨識率。
- macOS 系統辨識：使用系統內建的語音辨識。macOS 26 起在裝置端辨識；更早的系統在支援時要求裝置端辨識，否則是否上傳由系統決定。

文字潤飾可單獨開啟，預設服務是 DeepSeek，但不填金鑰就不會傳送任何文字。即使辨識使用本地模型或系統辨識，啟用潤飾並填寫金鑰後，轉寫文字仍會發往潤飾服務。同一頁還可以選擇錄音裝置、關閉開始／結束提示音，以及設定錄音時是否靜音其他聲音（預設開啟，會靜音整個預設輸出裝置，錄音結束後恢復）。

## 錄音與文字輸入

在要輸入文字的應用程式裡切換到水杉，然後：

- 按住右 Option 錄音，放開結束並辨識；按住期間按空格可鎖定錄音，之後無需繼續按住。
- 按 `Control + F9` 開始錄音，再按一次結束。這個快捷鍵需要在「系统设置 › 隐私与安全性 › 输入监控」中允許水杉輸入法，否則按下沒有反應；首次授權後請重新按鍵。
- 也可使用輸入法選單的「开始/结束语音输入」或懸浮工具列。

「按住右 Control+右 Option 录音」和「按住 Control+Command 录音」預設關閉，可在「语音快捷键」中開啟，不需要的快捷鍵也可以在那裡關閉。錄音中按 `Esc` 取消。第一次錄音會請求麥克風權限。辨識完成後文字輸入到目前應用程式；使用串流辨識時，錄音過程中就能看到轉寫預覽。

雲端批次辨識的單次錄音上限約 11 分鐘，到達上限時自動結束並提交已錄的部分；豆包串流辨識和本地模型不受這條限制。

## 資料與權限

選擇雲端服務時會上傳本次錄音；文字潤飾會上傳轉寫文字；服務收到的資料無法透過取消操作收回。本地模型全程在本機執行，辨識期間不發出網路請求。

如果無法錄音，請在 macOS 系統設定的「隱私與安全性 → 麥克風」中檢查水杉的權限，並確認所選錄音裝置可用。辨識失敗時，浮層會顯示服務回傳的原因；檢查 API Key、服務地址、模型或帳戶權限。隱私詳情見 macos-v0.52.0 的[隱私說明](https://github.com/metasequoiaime/msime/blob/macos-v0.52.0/PRIVACY.md)。
