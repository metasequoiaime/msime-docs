# macOS 使用指南

水杉 macOS 版由两部分组成：系统输入源「水杉输入法」，以及负责安装、设置和词库管理的设置应用 MSIME。当前发布的 DMG 是 universal 包，Apple 芯片与 Intel Mac 通用，要求 macOS 13 及以上版本。本文按 2026-10-05 发布的 macos-v0.52.0 整理；其他版本的功能以对应 Release 为准。macOS 版由 [msime](https://github.com/metasequoiaime/msime) 仓库发布。iOS 版通过 TestFlight 公开链接测试分发，不能用 macOS 安装包安装到 iPhone 或 iPad。

## 下载与安装

从 [msime Releases](https://github.com/metasequoiaime/msime/releases) 打开标签为 `macos-v0.52.0` 的版本；该页面同时列出 Windows、Linux 等其他平台的发布，请认准 `macos-v` 开头的标签。完整版下载 `msime-macos-0.52.0-universal.dmg`。同一版本还提供只含部分方案的水杉五笔、水杉拼音、水杉日语、水杉越南语和水杉藏文（文件名分别含 `wubi`、`pinyin`、`japanese`、`vietnamese`、`tibetan`），几个版本可以同时安装，输入源、设置和数据彼此独立。

1. 把 DMG 与 `SHA256SUMS` 下载到同一目录，在该目录运行 `shasum -a 256 -c --ignore-missing SHA256SUMS`，确认下载的文件显示 `OK`。
2. 打开 DMG，把水杉输入法（`MSIME.app`）拖进「应用程序」文件夹。只拖进去而不打开，系统里不会出现输入法。
3. 在「应用程序」里打开它。首次打开会显示安装窗口，点「立即安装」把输入法复制到当前用户的 `~/Library/Input Methods` 并登记，完成后点「进入设置」。
4. 按设置页顶部的提示，在「系统设置 → 键盘 → 文字输入 → 输入法 → 编辑…」中添加水杉输入法；提示里的「打开键盘设置」按钮可以直接跳到这里。
5. 在菜单栏的输入法菜单中选中水杉，或按 `Control + Space` 切换，打开文本框输入 `nihao`，按空格选词。

这台 Mac 从未装过水杉时，登记要到下次登录才生效：设置页会提示注销并重新登录，重新登录后再按第 4 步添加。`/Library/Input Methods` 里如果还有水杉的旧副本，设置应用会请你先用管理员权限把它移到废纸篓。默认的完整版只内置拼音和五笔所需的核心词库；日语、粤拼、注音词库和手写模型在设置里第一次用到时下载。

也可以用 Homebrew 安装，cask 下载的是同一个 DMG：

```sh
brew install --cask metasequoiaime/tap/msime
```

其他版本的 cask 是 `msime-wubi`、`msime-pinyin`、`msime-japanese`、`msime-vietnamese` 和 `msime-tibetan`。装完仍要按上面第 3 步打开一次应用并点「立即安装」。完整版的 cask 还会把 `msime-mcp` 放进 `PATH`，供在终端里配置的 AI 助手使用。

## 常用操作

| 操作 | 按键或入口 |
| --- | --- |
| 选择候选 | 空格选首选；`1`～`9` 选择对应候选，也可点击候选 |
| 提交原始字母 | `Enter` |
| 修改或取消 | `Backspace` 退格；`Esc` 取消 |
| 中英文切换 | 单按 `Shift`、`Shift + Space` 或 `Control + Option + Space`，或输入法菜单；可在设置「快捷键」页改为单击 Control 或关闭 |
| 英文候选模式 | `Control + Shift + E` 或输入法菜单 |
| 半角／全角 | 中文模式下 `Option + Shift + H`，任意模式下 `Control + Shift + Space`，或悬浮工具栏 |
| 中文／英文标点 | `Control + .`、输入法菜单或悬浮工具栏 |
| 简体／繁体输出 | `Control + Shift + F`、输入法菜单「繁体输出」或悬浮工具栏 |
| 翻页 | 默认 `-` / `=`、`,` / `.`、`Shift + Tab` / `Tab` 与 Page Up / Page Down；可在设置「输入 → 选词与翻页」中增减，`[` / `]` 和鼠标滚轮默认关闭 |

组词中单按 `Shift` 会把已输入的字母原样上屏后再切到英文；从菜单、悬浮工具栏或 `Control + Shift + E` 切换时则取消当前组词，不上屏任何内容。全角和中文标点的快捷键只改变当前应用，不改保存的设置；设置里的勾选项是每个应用的起始值。简繁转换只改变候选展示和上屏结果，不改写词库。

## 设置与候选窗口

通过输入法菜单的「水杉输入法设置…」、悬浮工具栏的设置按钮，或直接打开「应用程序」里的水杉输入法进入设置。常用页面包括：

- **输入**：中英文默认状态、选词与翻页、云候选和中英混输、候选学习、繁体输出、快捷模式、模糊音。输入方案除全拼外还有双拼（小鹤、自然码、首道、微软）、五笔 86／98、日语、韩语、粤拼、注音、越南语和藏文等，也可在输入法菜单的「输入方案」子菜单中切换。
- **辅助码**：全拼和双拼分别设置开关与方案，可选自然码、蓝天小雨点、首右 2.0、首右 Plus、小鹤等；候选旁显示辅助码提示。双拼还可开启键位提示（默认关闭）。
- **候选窗口**：横排／竖排、每页候选数和字号（12～32）等。
- **主题**：跟随系统、水杉、浅色、纸白、夜青、墨与自定义；外部皮肤包放在 `~/Library/Application Support/app.msime.macos/skins/<id>/` 下。
- **快捷键**、**悬浮工具栏**、**语音输入**、**手写输入**、**词库**、**AI 辅助**、**账号与同步**等其他页面。

正在进行的组词沿用开始时的设置，新设置在上屏或取消后用于后续输入。macOS 27 不允许输入法替用户启用新的输入源条目：切换到粤拼、注音、越南语、藏文等方案时，如果菜单栏没有对应条目，设置页「输入」里会列出还需添加的条目和所在语言，按提示在系统设置中手动添加。

## 本地快捷模式

在设置「输入」页的「快捷模式」中，各模式可单独开关。下表几项默认开启，在中文模式下使用：

| 快捷键 | 用途 | 示例 |
| --- | --- | --- |
| `Shift + U` | Unicode 码点 | `4e00` 对应“一” |
| `Shift + T` | 日期、时间、星期 | `rq`、`sj`、`xq` |
| `Shift + K` | 快捷短语 | 输入已设置的短语编码 |
| `Shift + E` / `Shift + M` | Emoji／颜文字 | 输入全拼、简拼、双拼或英文关键词 |
| `Shift + J` | 超级简拼 | `nh` 检索“你好”等候选 |
| `Shift + Y` | 临时英文 | 之后按英文处理，上屏后回到中文 |
| `Shift + R` | 临时日语 | 之后按日语罗马字处理，上屏后回到中文 |

计算与数字（`Shift + V`）、`/` 指令和 `@` 名单默认关闭，可在同一组开启。关闭某个模式后，对应组合照常输入大写字母。临时日语要先在「输入」页的「临时日语词库」中下载词库。表情也可通过输入法菜单的「水杉表情面板…」或悬浮工具栏菜单的「表情与符号…」输入。

## 语音与数据

识别服务、本地模型、录音快捷键和麦克风权限见 [macOS 语音输入](macos-voice.md)。选择云端识别时上传录音；本地模型和系统识别不上传音频；开启文本整理并填写密钥后，转写文本会发往整理服务。

按键、组词和候选学习在本机处理，以下几项例外：

- **云候选**：第一次激活输入法时弹出「联网功能」对话框，选「启用云候选」后，会把正在输入的拼写发给 Google input-tools 换回一条候选；回答之前不发请求，之后可在「输入」页的「云候选」更改。
- **候选词翻译**：新装默认使用「水杉账号」，把当前页的中文候选词发到 `api.msime.app`。没有登录时，输入法第一次激活会注册一个本机匿名账号。可在「标点与翻译 → 候选词翻译」改选腾讯云、小牛翻译、自定义 DeepLX，或不使用在线翻译。
- **匿名使用统计**：默认开启，只含版本、平台和随机安装标识等，不含输入内容；可在「关于」页关闭。
- AI 辅助、语音识别与文本整理默认没有密钥，不填写就不会发出请求。

学习数据、用户词库、下载的资源包和共享设置位于 `~/Library/Application Support/app.msime.macos/`，可在「维护与诊断 → 数据目录」移到别处。关闭候选学习只影响后续组词；「词库」页末的「清除全部学习数据」会永久删除候选词频、用户词库和拼音学习记录（包括自己新增的词条），输入方案等设置不变，请先确认不再需要。备份数据目录前先切换到其他输入法，避免复制正在写入的数据库。

## 更新与卸载

macOS 版没有应用内自动更新。设置「关于」页的「检查更新」（或悬浮工具栏菜单的「检查更新…」）查询新的 `macos-v` 发布，有新版本时点「前往下载」打开发布页。下载新 DMG，把应用拖进「应用程序」替换旧版并打开一次，设置应用启动时会刷新已安装的输入法。用 Homebrew 安装的运行 `brew upgrade --cask msime`。

卸载在设置「维护与诊断」页的「卸载」中点「卸载…」再确认：输入法移到废纸篓，默认保留词库、学习记录和偏好；勾选「同时删除词库、偏好与语音密钥」时一并删除。如果系统设置的输入源列表里还有水杉，设置应用会先打开键盘设置，请在「文字输入 › 输入源」里逐个移除后再确认卸载。之后把「应用程序」里的水杉输入法移到废纸篓。用 Homebrew 安装的可运行 `brew uninstall --cask msime`，加 `--zap` 同时删除设置、词库与缓存。

## 常见问题与反馈

- **输入源未出现**：确认已打开设置应用并完成「立即安装」；全新安装后注销并重新登录，再在「系统设置 → 键盘 → 文字输入 → 输入法」中添加；检查 `/Library/Input Methods` 里是否有旧副本。
- **快捷键输入大写字母**：确认当前是中文模式，且该模式在「输入 → 快捷模式」中开着。
- **设置没有立即生效**：先上屏或取消当前组词，再重新输入。
- **日语、粤拼或手写不可用**：在设置中选中对应方案或打开手写面板以下载资源包，并确认能访问 GitHub。
- **语音无结果**：检查麦克风权限、录音设备、模型或服务配置，详见语音输入页。

问题提交到 [msime Issues](https://github.com/metasequoiaime/msime/issues)，附 macOS 与输入法版本、所用版本（完整版或五笔等）、芯片架构、宿主应用和最小复现步骤。共享材料前移除实际输入内容和凭据。更完整的数据说明见 macos-v0.52.0 的[隐私说明](https://github.com/metasequoiaime/msime/blob/macos-v0.52.0/PRIVACY.md)。
