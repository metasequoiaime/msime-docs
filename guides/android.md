# Android 使用指南

水杉 Android 版是一个系统输入法，由键盘和同名的设置应用组成，支持 Android 9 及以上版本，目前是测试版，尚未上架应用商店。本文按 [msime](https://github.com/metasequoiaime/msime) 当前 `develop` 源码核对；安装包功能和版本以对应 Release 为准。不同版本可能存在功能差异，请同时查看对应 Release。

## 下载与版本

从[蒲公英下载页](https://www.pgyer.com/msime)或 [msime Releases](https://github.com/metasequoiaime/msime/releases) 中标签以 `android-v` 开头的版本下载 APK。每个 Release 提供几个互相独立的版本：

- `msime-android.apk`：完整版，包含全拼、双拼、五笔、手写等全部方案。
- `msime-android-pinyin.apk`、`msime-android-wubi.apk`：只带拼音或五笔的「水杉拼音」「水杉五笔」。五笔版只有五笔和手写，默认打开五笔拼音混输。
- `msime-android-japanese.apk`、`msime-android-vietnamese.apk`、`msime-android-tibetan.apk`：水杉日语、水杉越南语、水杉藏文，没有中文手写。

这些版本是不同的应用，可以同时装在一台手机上，彼此的设置和词库互不影响。每个 APK 旁边的 `.sha256` 文件可用来核对下载是否完整。

安装商店外的 APK 时，系统可能提示“未经检测”或“存在风险”，需要允许浏览器或文件管理器“安装未知应用”。

## 启用键盘

第一次打开应用会有新手引导，按提示操作即可；跳过了也可以在「我的 → 使用帮助」里找到同样的步骤：

1. 打开系统的「设置 → 系统 → 语言和输入法 → 屏幕键盘」（各品牌手机的菜单名称略有不同），或者点应用里的「打开系统键盘设置」直接跳过去。
2. 在屏幕键盘列表里打开水杉输入法的开关，按提示确认。
3. 点任意输入框，再点右下角的键盘图标，选择水杉输入法。

应用的「设置」页会显示键盘是否「已在系统中启用」和是否已「设为默认输入法」，没完成时可以直接点「去启用」「设为默认」。键盘列表里看不到水杉时，先确认开关已打开，再点输入框右下角的键盘图标翻一下列表。

## 升级

新版本直接覆盖安装，词库和设置不会丢失；所有版本用同一把密钥签名。也可以在应用的「我的 → 关于」里点「检查更新」，或打开「自动更新」：每天联网时检查一次，下载好后通知你安装。「更新通道」可以选稳定版或更早拿到新功能的预览版。第一次从应用内安装更新时，系统会要求允许水杉“安装未知应用”。

0.3.0 在部分设备上会提示「词库准备失败」、只能直接输入，Android 9 上打开应用会闪退，这两个问题都已在 0.3.1 修复，遇到时请升级到 0.3.1 或更新版本。

## 中英文切换

点键盘上的「中/英」键切换中文和英文。默认进入中文，切换后会按应用记住：在某个应用里换成英文，下次回到这个应用还是英文。网址、邮箱和密码输入框会临时进入英文，离开后恢复原来的状态；密码框里点「中/英」不起作用。

0.3.1 里还有一个问题：很多聊天框、搜索框和网页输入框（声明了“不需要输入建议”的输入框）每次都从英文开始。这个问题已经修复（[#5998](https://github.com/metasequoiaime/msime/issues/5998)），修复从 0.3.1 之后的下一个 Android 版本起生效。

长按「中/英」键会弹出系统的输入法选择框，可以临时换到密码管理器之类的其他键盘。

## 9 键与 26 键

在「设置 → 键盘 → 布局 → 中文键盘」里选择 26 键或 9 键。当前方案只有一种键盘时，这一项会提示到「输入」里换方案；只带一种方案的版本（例如五笔版）也只有一种键盘。

要换输入方案（全拼、双拼、五笔等），点键盘上「拼26」这类方案角标，在输入方案里选择；方案和语言的完整列表在「设置 → 输入 → 语言与方案」。

同一页的「布局」里还可以调整键盘高度、按键间距和行间距，以及 9 键左侧符号栏的内容。

## 输入方案、双拼与辅助码

输入方案在「设置 → 输入 → 语言与方案」里切换。点「普通话」可以选全拼、双拼（小鹤、自然码、微软、首道）、五笔（86 或 98）、注音、注音 9 键、笔画和手写；全拼用 26 键还是 9 键，在「设置 → 键盘 → 布局 → 中文键盘」里选。注音和笔画第一次选用时要先下载词库。粤语（粤拼）、日语、韩语、越南语和藏语在同一页的「添加语言」里添加，第一次添加时同样要下载对应的词典。以上是完整版的方案，水杉拼音、水杉五笔等独立版本只带各自的方案。

辅助码在「设置 → 输入 → 辅助码」里设置：全拼或双拼组字时，先按 Shift 再输入的字母用来缩小候选。「辅助码方案」按当前是全拼还是双拼分别保存，可选自然码、小鹤、蓝天小雨点、首右2.0、首右plus、加加等；没改过时双拼用蓝天小雨点，全拼用自然码。

0.3.1 里辅助码关不掉，这一页只有「辅助码方案」。从 0.3.1 之后的下一个 Android 版本起，同一处新增「启用辅助码」开关，关掉后 Shift 后面的字母不再用来缩小候选；还新增「在候选栏中显示双拼辅助码」（全拼方案下是「在候选栏中显示全拼辅助码」），关掉后候选旁不再标注辅助码，Shift 筛选照常可用。

双拼方案的 26 键键盘会在字母键底部标出这个键代表的声母和韵母。0.3.1 里这个标注关不掉；从 0.3.1 之后的下一个 Android 版本起，可以在「设置 → 键盘 → 布局 → 双拼键位提示」里关闭，关闭后键面只留字母。

## 整句联想

输入多个拼音音节时，键盘会用词库组出整句候选。「设置 → 表达 → 整句联想」有三档：「关闭」、「标准」（默认，只用词库组句）和「增强」。「增强」在标准之上加入开源的 chinese-ime-lm 整句重排模型，结合前文在整句候选里重新挑选首选，计算会多一些。水杉五笔等只带单一方案的独立版本不带这个模型，没有「增强」这一档。它做什么、实测效果与代价见官网的[神经联想](https://msime.app/model/)页。

## 浮动键盘、单手模式与平板

浮动键盘让整个键盘缩成一块面板悬在应用上面，应用不再被顶起，键盘挡住输入框时把面板拖开即可。按住面板顶部的横条拖动位置，点横条右端的「停靠」回到底部的完整键盘。打开方式有三种：「设置 → 键盘 → 布局」里的「浮动键盘」开关、键盘功能面板里的「浮动键盘」，以及工具栏按钮（默认不显示，在「设置 → 键盘 → 键盘工具栏」里打开）。

单手模式在键盘功能面板里打开，键盘收窄并推向一侧，另一侧可以换边或退出。浮动键盘打开时单手模式不生效，停靠后自动恢复。

平板、展开的折叠屏和二合一设备会使用居中的大屏键盘。「设置 → 键盘 → 布局」里的「横屏分离式键盘」只在平板横屏时生效，把 26 键和韩文键盘分成左右两半，方便双手握持时用拇指打字。

## 外接键盘

用实体键盘打字时，屏幕键盘会自动收起，只留下顶部一行：空闲时是工具栏，打字时是候选条。点工具栏最右边朝上的箭头可以回到完整的屏幕键盘，下一次用实体键盘打字时会再收起；拔掉或合上键盘后自动退出这个模式。

实体键盘上可以用 Shift+Space、Ctrl+Alt+Space 或单击 Shift、Ctrl 切换中英文，Ctrl+Shift+F 切换简繁，Alt+Shift+H 切换全角。候选前面标了数字时，按数字键 1–9 选择对应的候选。

## 语音输入与手写

语音输入的设置在「设置 → 语音输入」：识别语言可选普通话、粤语、英语或普通话 + 英语；「启动方式」可选长按空格、工具栏按钮或关闭。第一次使用时需要允许水杉使用麦克风。打开「离线识别」并下载「本地语音运行库」后，没有网络时会用本地模型识别，准确率略低。「上传语音以改进识别」默认关闭，开启后音频和识别结果会上传到水杉云并保存 180 天，隐私模式、密码框和不允许个性化学习的输入框里不会上传。

手写输入的设置在「设置 → 手写输入」。手写第一次使用时需要联网下载识别模型，之后在设备上识别。

### 不联网安装本地语音

本地识别要两样东西：「本地语音运行库」和至少一个本地模型。完整版和水杉拼音的安装包不带运行库，要另外准备；其他版本的安装包自带运行库，只需准备模型。两样都可以在应用里直接下载；网络慢或总是下载失败时，可以先用手机浏览器或电脑把文件下好（电脑上下的要先传到手机里），再在应用里从文件导入。0.4.1 起的版本支持从文件导入，下面按 0.6.0 的界面说明。

1. 在「设置 → 语音输入」的「识别」分页打开「离线识别」，或者在「服务」分页把识别服务选成「本地模型」。之后「服务」分页里会出现「本地识别准备」和「本地模型」两组。打开离线识别或选用本地模型时，应用会自动开始下载运行库。
2. 导入运行库：在「本地识别准备」里点「从文件导入运行库」。运行库正在下载时这一项不显示，先在「本地语音运行库」那一行点「取消」；运行库显示「已就绪」时也不显示，不需要再导入。
3. 导入模型：在「本地模型」里点「从文件导入」，再选一个还没装好的模型。正在下载的模型不在这个列表里，要先在它那一行点「取消」。
4. 弹窗会列出这一项要下载的文件和大小，点「下载地址」可以直接用浏览器打开。文件都下好后点「选择文件」，把它们一起选上。应用按长度和内容（SHA-256）认文件，改了文件名也没关系；文件不完整或不对时什么也不会装上。

当前版本要的文件如下，都是 sherpa-onnx 项目在 GitHub Release 上发布的原始文件。模型只需装要用的那一个：

| 用途 | 要下载的文件 | 大小 |
| --- | --- | --- |

| 中英流式 | [sherpa-onnx-x-asr-480ms-streaming-zipformer-transducer-zh-en-punct-int8-2026-06-05.tar.bz2](https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-x-asr-480ms-streaming-zipformer-transducer-zh-en-punct-int8-2026-06-05.tar.bz2) | 133.9 MB |
| 中英整句 | [sherpa-onnx-x-asr-zipformer-transducer-zh-en-punct-int8-2026-06-03.tar.bz2](https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-x-asr-zipformer-transducer-zh-en-punct-int8-2026-06-03.tar.bz2) 和 [silero_vad.onnx](https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/silero_vad.onnx) | 136.4 MB + 0.6 MB |
| 快速整句 | [sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17.tar.bz2](https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17.tar.bz2) 和 [silero_vad.onnx](https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/silero_vad.onnx) | 163.0 MB + 0.6 MB |

- 运行库导入的是整个 `.aar` 文件，模型导入的是 `.tar.bz2` 压缩包本身，都不要解压。
- 中英整句和快速整句用的是同一个 `silero_vad.onnx`，下载一次就够，两个模型导入时都选它。
- 文件名和版本会随水杉的版本更新。权威清单是 msime 仓库 `develop` 分支上的 [voice-runtime.lock.json](https://github.com/metasequoiaime/msime/blob/develop/resources/voice-runtime.lock.json)（`platforms.android` 一项）和 [local-asr-models.json](https://github.com/metasequoiaime/msime/blob/develop/resources/local-asr-models.json)（每个模型的 `archive`，以及 `extra` 里带 `url` 的文件；标了 `desktop_only` 的模型只在电脑上提供），里面也写了每个文件的 SHA-256。`develop` 可能比你装的版本新，和应用弹窗里列的文件不一致时，以弹窗为准。

## 常用操作

- **选择候选**：点候选栏里的词上屏；候选多于一行时，点右端的箭头展开整页。
- **删除**：按住删除键会逐渐加速连删；按住后往上滑，键上方会出现「快速删除」框，滑进框里松手会删掉光标前的全部文字，滑回框外再松手则什么也不删。
- **换皮肤**：点键盘工具栏上的衣架图标，或在「设置 → 皮肤」里选择。
- **隐私**：键盘默认离线，只有使用云候选、AI、语音、账号同步等功能时才联网，详见 [PRIVACY.md](https://github.com/metasequoiaime/msime/blob/develop/PRIVACY.md)。

## 桌面 CLI 与 MCP

Android 发布 APK 是原生输入法宿主，不包含桌面版的 `msime`、`msime-mcp` 或 MCP stdio 服务。需要查询候选、驱动测试会话或连接 AI 助手时，请在安装了 macOS、Linux 或 Windows 桌面版的电脑上使用对应的 CLI；Android 的设置和输入数据不会自动提供给桌面 CLI。桌面命令与权限说明见[命令行与 MCP](cli-mcp.md)。

## 反馈问题

在应用的「我的 → 帮助与反馈」里提交，可以附上截图和诊断信息；也可以先搜索 [msime Issues](https://github.com/metasequoiaime/msime/issues)，没有相同问题时再新建，并写明手机型号、Android 版本和水杉版本。
